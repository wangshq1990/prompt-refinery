# 领域权威溯源（F4） · 检索契约与权威原型

## 目的

把 B4 / B7「真实数据原则」从口头要求落地为可执行的检索动作：对**事实 / 数据 / 专业知识类**任务，联网检索 **3 个该领域的权威来源**并标注出处，再用来源支撑「老手避坑 / 杠杆点（R1 深度触发）」，提升交付物的数据可靠性。

**不触发 F4 的情形**：纯创意 / 虚构类（写歌词、编段子、虚构故事、纯文案脑暴）——这类不依赖可核验事实，无需溯源。

## 什么是「权威来源」（可信度分级）

按可信度从高到低，检索与挑选时优先取高位：

- **T0 官方 / 监管 / 立法 / 司法**：政府站（`.gov` / `.gov.cn`）、监管机构、立法与司法机关、官方统计与公报。
- **T1 标准 / 学术 / 专业机构**：国家标准组织、顶尖高校（`.edu`）、学会 / 协会、同行评审期刊、官方指南 / 药典 / 规范 / RFC。
- **T2 公认行业权威**：头部机构官方发布、权威媒体深度报道、知名从业者**可核验**的方法论（须能查到作者与机构）。
- **排除项**：营销软文、无署名自媒体、论坛问答、AI 生成内容、任何无法核实的「据说 / 网传」。

## 领域权威原型（检索时优先匹配的类型）

- **法律（中国内地）**：立法机关(npc.gov.cn) / 最高人民法院(court.gov.cn) / 司法部(ministryofjustice.gov.cn) / 官方法规数据库（如北大法宝、国家法律法规数据库）。
- **金融 / 理财 / 投资**：中国人民银行(pbc.gov.cn) / 证监会(csrc.gov.cn) / 国家统计局(stats.gov.cn) / 官方投资者教育基地 / 央行/证监会发布的官方指引。
- **医疗 / 健康**：国家卫健委(nhc.gov.cn) / 国家药监局(nmpa.gov.cn) / 官方临床指南与药典 / 顶尖医学院与三甲医院官方发布。
- **教育 / 学术**：教育部(moe.gov.cn) / 官方课程标准 / 高校与学会 / 同行评审文献。
- **软件工程 / 安全**：官方文档 / RFC / 语言与框架官网 / 权威安全机构（如 OWASP） / 官方漏洞库（CVE / NVD）。
- **营销 / 产品**：市场 / 行业监管部门（如市场监管总局） / 平台官方规则中心 / 权威行业研究报告机构 / 官方统计。
- **其它领域（通用）**：对应国家主管部门官网（`.gov` / `.gov.cn`）+ 该领域公认标准 / 学术机构 + 权威行业组织；按 `domain-portability.md` 的通用骨架处理，并**明确标注「未加载领域默认值，来源为通用权威渠道」**。

## 运行时检索流程

1. 取第 1 步判定的**领域** → 选上面对应的「权威原型」。
2. 用 **WebSearch** 检索「`<领域> <本次主题> 权威来源 / 官方 / 指南 / 规范 / 数据`」，**优先官方站与 `.gov` / `.edu` / `.org`**。
3. 从结果中挑 **3 个**最权威且可核验的来源，记录：`标题 + URL + 权威性说明（属于 T0/T1/T2 哪一级）+ 与本次任务的相关点`。
4. 用这 3 个来源支撑 **R1 深度触发**的 2–3 个避坑 / 杠杆点，**每条标注其依据的来源**。
5. **联网失败 / 无果降级**：明确标注「未能联网核实，以下内容基于通用知识，关键事实请你自行向权威渠道核实」，**不得伪造 URL 或捏造来源**。

## 引用格式（交付物中展示）

```
参考来源（3）
1. <标题> — <机构 / 出处> (<URL>) · <一句为什么权威 + 与本任务的相关点>
2. <标题> — <机构 / 出处> (<URL>) · <……>
3. <标题> — <机构 / 出处> (<URL>) · <……>
```

纯创意类不输出此块。

## 与既有规则的衔接

- 是 B4 / B7「检索真实来源、标注出处、禁止编造」的**可执行动作**（而非仅口头要求）。
- 实现 **R1 深度触发**（rubric P3 维度：老手避坑 / 杠杆点 / 取舍），让领域深度从「看模型心情」变「必出项且可溯源」。
- 不违反 **B8**：F4 仅就「领域 + 主题」发起检索，**不发送用户原始提示词全文、不回传用户数据、不用于训练**；纯创意类不触发。
