# 五要素方法论（严谨版）

本文件是 Forced Convergence 引擎的深度依据。每个要素给出「认知原理 / 反模式 / 高质量写法 / 评分点」。其中带「修正」标记的，是对原书表述的必要校准——原书方向正确，但部分断言在当代模型上需要修正。

## 1. 角色 Role

**认知原理**：给模型一个身份，会偏置其权重网络，让它优先调用该身份对应的语料与措辞。身份的价值不在「名头」，而在它携带的「评判标准」。

**反模式**：

- 堆头衔：「顶级专家 / 二十年经验 / 行业大拿」。修正：这类修饰对新一代推理模型增益有限，模型不会因为你说「二十年」就更专业。
- 只给职业不给标准：「你是一个营销专家」。

**高质量写法**：身份 = 职业锚点 + 可观察的评判标准。例如「你是餐饮营销操盘手，说话一针见血，每个方案必须标注失败率，只给可落地动作，拒绝对空谈战略。」

**评分点**：角色是否包含至少一条可观察的评判标准（如语气、失败率、落地要求），而非仅头衔。

## 2. 背景 Context

**认知原理**：模型没有你的实时战况。不喂背景，它就对空气挥拳，给出与你资源、限制完全脱节的方案。

**反模式**：

- 零背景：「我的咖啡馆生意不好，给个主意。」
- 把背景当成「提示词技巧」本身。修正：背景里的「零成本 / 50 元 / 3 个月」是你要填的真实内容，不是公式的一部分。

**高质量写法**：背景 = 竞争/环境 + 硬限制 + 仅有的筹码。例：「大学城旁，周边 5 家瑞幸 3 家库迪打价格战；资金只够 3 个月；唯一优势是店里有亲人流浪猫、空间大适合自习。」

**评分点**：背景是否包含至少一项真实限制（钱/时间/人力/竞争），让方案无法脱离约束空想。

## 3.目标 Goal

**认知原理**：目标是「交付物契约」。它把模糊意图变成可勾选的产出清单，消除模型的自由发挥空间。

**反模式**：

- 软词：「探讨一下」「分析一下」「你觉得呢」。
- 单一笼统：「帮我解决这个问题」。

**高质量写法**：祈使句 + 编号必须项。例：「设计一套零成本『猫咪自习室』裂变引流方案，必须包含：1. 吸引大学生首次进店的钩子；2. 小红书打卡的裂变机制；3. 锁住复购的连环套。」

**评分点**：目标是否用祈使句，且拆成了 ≥2 个可独立勾选的必须包含项。

## 4. 约束 Constraint

**认知原理**：约束是「生死红线」，对抗模型爱写长篇正确废话的倾向。严苛的物理限制会逼出高信息密度的输出（所谓「戴着镣铐跳舞」）。

**反模式**：

- 无约束：放任模型输出几万字宏大战略。
- 约束互斥：「详尽」与「极短」并存；「列 3 个隐患」+「800 字」+「表格」三者叠加逼模型牺牲深度。

**高质量写法**：约束至少覆盖四类——禁用词/文风、预算或资源上限、语气、字数或篇幅；超过 4 条时标注优先级。例：「1. 禁用赋能/底层逻辑/抓手等黑话；2. 动作成本 ≤50 元/天；3. 语气冰冷客观；4. 总字数 ≤800。」

**评分点**：约束是否覆盖 ≥2 类（禁用词/预算/语气/篇幅），且无明显互斥。

## 5. 格式 Format

**认知原理**：模型同时是排版工。提前规定呈现形态，可省去你二次整理的成本，直接复制即用。

**反模式**：等模型自己输出一大段无结构文字。

**高质量写法**：指定具体形态与列名。例：「用 Markdown 表格输出，列含『具体动作 / 极低成本的实现方式 / 预估拉新人数』；表下方用三个加粗要点列出最可能导致流产的隐患。」

**评分点**：格式是否规定到「可直接使用」的程度（含列名/结构），而非笼统说「排版好看」。

## 6. 验收 Acceptance（可选但推荐）

**认知原理**：合格线是返工过滤器。没有它，你只能拿到结果后再判断「行不行」，往往要再绕一轮。

**高质量写法**：写明判定条件与失败自查。例：「每个动作必须能在 50 元/天内独立完成；任一动作做不到即视为不合格，请重写。」

**评分点**：验收是否给出可判定的合格条件，而非「尽量好」。

## 综合评分（产出提示词的自检）

给最终提示词打勾：五槽齐全、角色含标准、目标已拆项、约束无互斥、格式可直接用。任一项缺失即应回补。
