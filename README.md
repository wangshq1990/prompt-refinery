# 提示词精炼厂 · Prompt Refinery

> 把模糊、口语化的 AI 任务请求，收敛成一份**专业、可直接复制**的提示词，并给出「优化前 / 优化后」评分对照与多领域模板一键套用。
> A prompt-refining skill that turns vague requests into professional prompts — by default it only refines (shows the prompt), and executes only on your explicit opt-in.

**版本**：v1.0.0 · **格式**：Agent Skill（`SKILL.md`） · **许可**：MIT · **平台**：WorkBuddy（marketplace 上架）

---

## 它解决什么问题

大模型的输出是发散性的概率分布。只说「帮我写个方案」，得到的是通用、冗长、不可执行的内容。本 Skill 用五个硬槽位把分布收敛到可交付：

| 槽位 | 回答的问题 | 缺它后果 |
|---|---|---|
| 角色 Role | 谁来做、用什么**可观察的评判标准** | 通用实习生式泛泛而谈 |
| 背景 Context | 在什么真实条件下做（筹码、限制、环境） | 给出超出能力或预算的方案 |
| 目标 Goal | 要什么**具体交付物**，拆成 1/2/3 个勾选项 | 「探讨一下」式软弱内容 |
| 约束 Constraint | 绝不能怎样（禁用词、资源上限、语气、篇幅） | 几万字正确的废话 |
| 格式 Format | 最终以什么形态交付（表格 / 大纲 / JSON） | 需二次排版 |

第 6 槽「验收 Acceptance」可选，用于写明合格线与自查方式，显著减少返工。

## 与同类工具的核心区别：默认「纯加工」，执行 opt-in

很多提示词工具在生成提示词后会**默认自动帮你把任务跑完**。提示词精炼厂刻意**反其道而行**：

- **默认只做纯加工（状态 A）**：补全五要素、做冲突检测、给出「优化前 / 优化后」评分对照，然后**在对话内展示精炼后的提示词并停下等待**——**不自动执行**你的真实任务。
- **执行是 opt-in（状态 B）**：只有你显式说「执行 / 开始做 / 按这个做」时，才以该提示词为任务简报同会话执行真实任务。
- **仅展示（状态 C）**：如果你开头就说「只要提示词 / 给别处 AI / 我自己拿去用」，则加工并展示后**执行永久关闭**，即便之后说「执行」也不会执行——因为你本就要拿去别处用。

这样你永远先看清「将要交给 AI 的提示词」，再决定是否真去执行，避免被自动执行吓一跳。

## 三大新能力（F1 / F2 / F3）

- **F1 · 优化前 / 优化后评分对照**：对「你的原提示词」和「精炼后提示词」分别打分。确定性维度（覆盖率、约束冲突）由脚本 `scripts/build_prompt.py` 对两者各跑一次 `--json` 得出；质性维度（可读性 / 完整性 / 约束明确度 / 可执行性）由模型评估。对照可观察地体现提升（缺槽减少、冲突消除、质性分提高）。
- **F2 · 多领域模板一键套用**：内置营销 / 软件工程 / 学术 / 法律 / 数据分析 / 产品六大领域模板（见各 `references/domain-profiles/*.md` 的「模板骨架」段）。说一句「用营销模板给我起个头」，即可生成领域最佳实践骨架，再微调。未覆盖领域走通用骨架兜底。
- **F3 · 对话内交互微调**：展示后你可以要求「更简洁 / 加一条约束 / 换成英文 / 换角色 / 改背景」，技能在**对话内**迭代改写并重新展示，**全程不落盘**。

## 使用流程

1. **触发**：说「帮我把这个需求变成给 AI 的提示词」「怎么写 prompt 才不让 AI 说废话」「把这个任务结构化一下再交给 AI」等。
2. **补全与适配**：技能判领域、逐槽追问、加载领域档案或套用 F2 模板、组装方头括号提示词。
3. **确定性校验**：调用 `scripts/build_prompt.py` 检查五要素覆盖率、约束互斥、约束数量（仅打印，不写文件）。
4. **F1 评分对照**：输出优化前 / 优化后对照（确定性分来自两次 `--json`，质性分四维度）。
5. **对话内展示并停下等待**：展示最终提示词 + 适配说明 + F1 对照；引导你「回复『执行』开始做 / 『微调 X』继续改 / 或自行复制走」。
6. **后续轮次**：说「执行」→ 状态 B 同会话执行；说「微调 X」→ F3 对话内迭代重展示；否则停在状态 A。

> 若开头命中 Q1（只要提示词 / 给别处 AI），第 1 步即进入状态 C，执行永久关闭。

## 安装

将本目录整体放入你的 Agent 的 skills 目录，保持目录名为 `prompt-refinery`。例如 WorkBuddy：

```
~/.workbuddy/skills/prompt-refinery/
```

无需安装依赖、无需联网、无需 API key。`scripts/build_prompt.py` 仅使用 Python 标准库。也可在仓库内运行 `./sync_to_skills.sh` 自动同步到上述目录。

## 校验脚本

```bash
# 默认只打印到屏幕，不写任何文件
python scripts/build_prompt.py --input example.json

# 以 JSON 输出结构化结果（F1 确定性分数据源）
python scripts/build_prompt.py --input example.json --json

# 运行自检（含 6 领域档案 + 模板骨架守卫）
python scripts/selftest.py
```

`scripts/build_prompt.py` 以退出码 0 / 1 表示五要素齐全 / 缺失（INCOMPLETE），并给出约束互斥与数量的警告。设计上不联网、不启动子进程、不读取环境变量。

## 边界

本 Skill 明确不做以下事情：

- **B1** 不在对话外自动执行删除、覆盖、发送、发布、付费、外部 API 写入等副作用动作
- **B2** 不读写用户个人文件、配置或凭证；提示词仅在对话内展示，不落盘
- **B3** 不索要 API key、密码、token
- **B4** 不编造领域事实或数据；事实/数据类任务须基于真实可查来源并标注出处
- **B5** 用户未提供真实任务信息时不臆造、不空执行
- **B6** 不跨会话、不后台常驻
- **B7** 真实数据接地：事实/数据类任务提示词须含真实数据原则
- **B8** 不收集、不上传用户提示词数据；F1/F2/F3 均在对话内完成，不联网
- **B9** 免费上架，不含付费墙、不引导付费
- **B10** 不越权；状态 C 下即便说「执行」也拒绝执行

允许的是：同会话内执行用户真实任务（A1，仅 opt-in）、对话内展示提示词供调整（A2）、评分与模板增强（A3，均对话内、不落盘）。提示词仅在对话内展示，不落盘。
